how this dashboard works

Open any box with its <> button. Each one has four tabs: q runs on the server, and its result is handed to the box's js as data, along with body (this element) and box. html and css are the box's own markup and styles.

The numbers come from a demo trade table the server builds at startup. Point a q tab at your own tables (select ... from trade where date=.z.d) and every box here keeps working unchanged.

Drag a box by its header, resize from the bottom-right corner, click empty grid to add one. Save layout writes this dashboard back to layouts/example, so save it under a new name if you want to keep the original around.
